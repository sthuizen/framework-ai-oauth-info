Privacy policy

Framework AI Backup is used solely by its owner for personal backups. It requests Google Drive per-file access (drive.file) to create and manage the backup repository files made by this application. File contents and backup metadata are encrypted locally by Restic before upload. Google receives the encrypted repository and associated service metadata under Google's policies. OAuth credentials remain on the owner's device and in any separately secured recovery copy. This application has no independent analytics, advertising, data-sale or developer collection service. The public website's hosting provider may process standard request logs. Backup retention is controlled by the owner. Revoking this app's access stops future backup access but does not itself delete existing Drive data. Recovery requires the repository encryption password and appropriate Google account and OAuth access. This is client-side encrypted backup, not immutable storage.
